# GenTex: LaTeX Document Generator with AI Assistance

GenTex is a web application that combines LaTeX document generation with AI assistance, providing an intuitive interface for creating and editing LaTeX documents with real-time PDF preview.

## Features

- **AI-Powered LaTeX Generation**: Generate LaTeX code from natural language descriptions
- **Real-time PDF Preview**: See your changes instantly with live PDF compilation
- **Interactive Editor**: Feature-rich LaTeX editor with syntax highlighting
- **AI Assistance**: Get help with LaTeX commands and troubleshooting
- **File Management**: Upload and manage images and other files for your documents
- **User Authentication**: Secure user accounts with login/register functionality
- **Responsive Layout**: Adjustable split-screen layout with resizable panels

## Prerequisites

- Python 3.8+
- Node.js 14+
- LaTeX distribution (e.g., TexLive)
- OpenAI API key
